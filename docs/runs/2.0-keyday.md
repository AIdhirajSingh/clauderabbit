### 2.0 architecture (from `docs/2.0/DESIGN.md`, `docs/runs/2.0-backend.md` and the tree at `dd89296`)

One scan per request inside a Vercel Node function. Every scan runs the code in a fresh E2B VM.

Entry points
- `app/api/scan/route.ts`: `POST /api/scan`, NDJSON (SSE with `Accept: text/event-stream`), `runtime nodejs`.
  Body parsing, caller identity, rate limit and `executeScan` live in `lib/server/scan-service.ts`.
- Replay: `app/api/runs/[runId]/events/route.ts`, `app/api/scan/replay/route.ts?target=&sha=`.
- Remote MCP: `app/mcp/route.ts` runs `executeScan` in process (`surface "mcp-remote"`); text from
  `lib/server/report-text.ts`. OAuth: `app/oauth/token/route.ts`, `app/oauth/register/route.ts`,
  `app/.well-known/oauth-authorization-server/route.ts`, `app/.well-known/oauth-protected-resource/mcp/route.ts`,
  `lib/server/oauth.ts`.
- Other routes: `app/api/export/{markdown,pdf}/route.ts`, `app/badge/[owner]/[repo]/route.ts`,
  `app/auth/callback/route.ts`.
- CLI: `cli/src/index.ts`, `cli/src/commands/{scan,mcp-install}.ts`, client `cli/src/lib/scan-api.ts`
  (POST `${CLAUDE_RABBIT_SITE_URL}/api/scan`, Bearer `cr_cli_`, `x-clauderabbit-client: cli`).
- stdio MCP: `mcp-server/src/index.ts`, `mcp-server/src/tools/scan.ts`, client `mcp-server/src/scan-api.ts`
  (copy of the CLI client).
